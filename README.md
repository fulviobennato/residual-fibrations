# Residual Fibrations: Exact Reconstruction from Partial Information

**Author:** Fulvio Bennato  
**Independent Researcher — Napoli, Italy**  
**ORCID:** 0009-0006-4343-3967

## Overview

This repository contains a public archival snapshot of the manuscript:

**Residual Fibrations: Exact Reconstruction from Partial Information**

The work develops a mathematical framework for reconstructing structure from partial information while retaining unresolved information as typed residual fibres, kernel relations, factorization data, and higher coherence structures rather than collapsing uncertainty into a single scalar quantity.

The framework connects categorical reconstruction, Grothendieck fibrations, sufficiency, information geometry, operator algebras, modular theory, algebraic quantum field theory, causal reconstruction, and residual completion. :contentReference[oaicite:0]{index=0}

## Archival purpose

This repository is maintained as a **public timestamped research record**.

The repository contains:

- the archived manuscript PDF;
- its corresponding **OpenTimestamps (`.ots`) proof**;
- Git commit history providing an additional public record of publication time.

The OpenTimestamps proof is cryptographically bound to the exact PDF bytes. Any modification of the PDF produces a different cryptographic hash.
